## What is MEGABIBLE.net?
- MEGABIBLE.net is the #1 Bible site in the WORLD (coming soon)

## What is MEGABIBLE.git?
- MEGABIBLE.net's core features are hosted in this repo, which include an elegant simple bible reader that works great on mobile and desktop, a bible typing engine with tracking for the entire 91-book corpus, and a studying system which allows the collecting and organization of verses. User accounts are explicitly nonexistent, with all data saved to localstorage.
- This repo represents the MEGABIBLE.net core infrastructure and does not include any Bible data (verses, chapters, etc) as those are already hosted on Github and elsewhere (see credits below).
